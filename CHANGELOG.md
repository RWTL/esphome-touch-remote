# Changelog

This project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Secret and build-output protection through `.gitignore`.
- A generic starter configuration with placeholder Home Assistant entities.
- Project version metadata and an ESPHome compatibility policy.

### Added

- Initial public release of the modular LVGL remote.
- Lights, LED zones, Apple TV, appliances, power, and settings pages.
- English and Italian interface text.
- Editable STEP sources for the prototype enclosure.
